## 5. 本轮已实施优化

### V17-01：SQL transaction begin-cancellation guard

`Framework/sqlclient.Client.transactionAttempt` 在 `BeginTx` 成功后立即检查 caller context。若取消已发生，则不执行用户 callback，直接 rollback、结束 transaction span，并返回 `context.Canceled` 或 `context.DeadlineExceeded`；rollback 失败按既有错误合并规则处理。这样避免 callback 在首次 SQL 操作前执行不可回滚的外部副作用，也不改变正常提交、callback 错误、panic 或 PostgreSQL 可重试错误路径。新增确定性 scripted-driver 测试验证 callback 未调用、rollback=1、commit=0 和取消错误；包级 test、race、vet 均通过。

该保护只覆盖仓库内 BeginTx/取消竞态，不证明真实 PostgreSQL 驱动、网络分区、跨进程事务、exactly-once、PITR 或 RPO/RTO。韧性、故障与恢复由 9.60 保守调至 9.63，加权贡献由 0.2880 调至 0.2889；未舍入综合评分由 9.8441 升至 9.8450，三位展示值由 9.844 升至 9.845，等级仍为 A−；`MSFront` 未修改。

V17-01 完成后，仓库内可诚实推进项已清空；V17-02 继续保持 `not_recorded`，等待目标环境原始输出、环境指纹、不可变 run URL、哈希和独立 verifier。

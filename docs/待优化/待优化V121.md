## 3. V121-01 实施约束

- 只有所有 application header 验证成功后才复制 body；非法消息不得保留未交付 body clone。
- 不得改变 `FetchMaxWait`、`FetchContext`、取消/deadline 优先级、迟到结果拒绝、body/header clone、W3C trace/baggage、Publish/Process、ack/DLQ/lease、错误 sentinel 或 public API。
- 新增 helper benchmark 与 legacy 对照；benchmark 输入在计时循环外构造，只报告同机相对耗时与分配。

## 3. V118-01 实施约束

- 新 helper 对不超过 64 bytes 的值按字节拒绝 `0x00`、`0x0a`、`0x0d`；更长值使用等价的标准库回退。空值、合法 ASCII、UTF-8 和不含这三字节的任意序列继续接受。
- 必须对全部 256 个单字节输入与 `!strings.ContainsAny(value, "\r\n\x00")` 比较，并覆盖多字节、非法 UTF-8、开头/中间/结尾控制字节和长值。
- 2 项、3-8 项、9-64 项和 `MaxHeaders > 64` 回退四条生产分支必须统一调用 helper，避免分支语义漂移。
- 名称可见 ASCII、大小写重复、数量/总字节限制、body/header clone、W3C trace、context、panic、低敏错误和公开 API 全部不变。
- benchmark 输入在循环外构造并保留 test-only legacy 对照；不得通过删除校验换取性能，不得外推生产容量。

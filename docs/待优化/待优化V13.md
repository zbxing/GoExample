## 1. 版本边界

V12 的仓库内实现、自动测试、失败门禁、文档与本地证据范围已经完成。V13 只承接 V12 尚未取得的目标环境、远端运行、外部系统、生产部署和审批证据，不回退 V12 已完成状态，也不把 workflow 定义、本地 loopback、未签名 manifest 或合成 workload 当作生产完成证明。

本文件是 2026-08-26 起唯一最新待优化清单。后续每轮只执行一个互斥动作：若 V13 尚有未完成项，则继续实施 V13；仅当 V13 全部完成后，才重新评估并创建下一版本。

## 3. 拆分顺序

1. 先完成 V13-01 至 V13-04 的外部信任边界：edge、Redis、身份和审计。
2. 再完成 V13-05 至 V13-07 的数据面、性能与交付实证；这些任务可以共享目标环境，但证据和完成判定必须独立。
3. 最后完成 V13-08 的真实消费者迁移和 V13-09 的综合长稳/恢复审批。

任何任务都不得仅凭配置、workflow、测试替身或本地 loopback 标记完成。无法提供某项强保证时，必须记录已批准的非目标、替代控制和残余风险，不能用文档声明代替运行证据。

## 4. 证据要求

- 每个工作包必须记录目标环境标识、不可变版本/digest、完整命令、开始/结束时间、退出状态、原始输出和制品 SHA-256。
- 远端运行必须记录可访问的 run URL、commit SHA、runner/image/toolchain 指纹和签名或平台 provenance；环境不兼容时不得执行固定性能回归阈值。
- 故障与恢复工作包必须记录注入点、观测到的失败、恢复步骤、数据一致性结果、RPO/RTO 实测值和责任人审批。
- `targetEdge`、`productionSharedStore`、`postgresRecovery`、`natsBroker`、`linuxRemoteBenchmark`、`signedRelease` 等边界只能由严格 verifier 根据完整制品更新，当前未取得的状态继续保持 `not_recorded`。
- `MSFront` 不在 V13 范围内，前端评分沿用现有基线且不因服务器侧工作上调。

## 5. 评分规则

- V13 在 V12 关闭时从 **9.493/10** 开始；本轮仓库内增量完成后当前为 **9.508/10**。创建或拆分文档本身不加分。

## Implementation Update (2026-08-26)

Billing now has a strict OpenAPI-to-Framework route parity test covering all 14 registered public operations, including deprecated health aliases and shared Example endpoints. Its generated SDK is regenerated from the same contract and now has package-level behavior coverage for its public-operation copy, every generated method's request mapping to the published method/path and parameter/body contract, gateway prefixes, request editors, envelope decoding, server URL safety, and response-size limit. The Billing service module also drives that generated SDK through its real `httpapi.NewHTTPHandler` and verifies the full summary envelope. The SDK generator accepts OpenAPI object schemas with `additionalProperties: true` as `map[string]any`. Root Go `test`, `cover`, `race`, `vet`, and `vuln` tasks now honor `GO_PROJECT` and include only Framework, the selected project, and its registered SDK; the default remains the complete workspace. These are repository-local V13-08 improvements only. V13-01 through V13-09 production and remote evidence remain `not_recorded`.

## 4. 实施记录

`Framework/sqlclient.Client.transactionAttempt` 在 callback 成功后、调用 `databaseTx.Commit()` 前再次检查 caller context。若已取消，立即 rollback 并完成 transaction span，返回 `context.Canceled` 或 `context.DeadlineExceeded`；rollback 失败按既有错误合并规则处理。新增 `TestTransactionRollsBackWhenCanceledBeforeCommit`，验证 callback 触发取消后 callback 返回 nil、最终只 rollback 一次且 commit 次数为零。正常提交、callback 错误、panic 与 PostgreSQL 可重试错误路径保持不变。

该保护只覆盖仓库内 SQL 提交竞态，不证明真实 PostgreSQL 驱动、网络分区、跨进程事务、exactly-once、PITR 或 RPO/RTO。韧性、故障与恢复维度由 9.63 保守调至 9.65，加权贡献由 0.2889 调至 0.2895；未舍入综合评分由 9.8450 升至 9.8456，三位展示值由 9.845 升至 9.846，等级仍为 A−。`MSFront` 未修改。

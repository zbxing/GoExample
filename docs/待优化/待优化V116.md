## 3. V116-01 实施约束

- 只将固定数组从 4 扩展到 8；不得删除或延迟任何 header 校验。
- 0-8 header 用 `strings.EqualFold` 检测 Go map 中大小写不同的重复名称，9-64 header 保留归一化 map。
- 名称必须继续是可见 ASCII；值继续拒绝 CR/LF/NUL；总字节使用溢出安全的剩余预算检查。
- publish/process 的 body/header clone、W3C trace、context、panic、错误隐私和公开 API 不变。

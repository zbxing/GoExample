## 1. 版本边界与互斥判定

V97-01（标准 JSON 媒体类型规范化 fast path）已完成并通过仓库内验收。V97-02/V97-03 仍只依赖真实 edge、DNS、证书、HTTP/2/3、正式 IdP/MFA、生产 Redis/PostgreSQL/NATS、KMS/SIEM、跨主机恢复、目标容量、远端不可变制品和组织审批。全面复评发现幂等指纹对生产唯一使用的标准 `If-Match` 名称仍每次调用 `strings.ToLower`，可以在不改变摘要字节的前提下消除一项临时分配，因此本轮执行分支 B：覆盖架构与性能评估、生成 V98，并立即实施 V98-01。

评分继续采用 20 个非前端维度，权重直接合计 100%，综合分为 `sum(维度分 x 权重)`。V97 完成暨 V98 实施前基线为 `9.926425/10`；V98-01 完成为 `9.927175/10`，实际增量 `+0.000750`。

## 2. 全面复评发现

1. `Framework/httpapi.idempotencyRequestFingerprint` 必须按固定顺序将 method、原始 URL、principal、规范化媒体类型、可选 fingerprint headers 与 body 以长度前缀写入 SHA-256；V96/V97 已分别消除摘要结果切片和标准 JSON MIME 规范化的临时开销。
2. `application_command.go` 的生产调用只传入 `fiber.HeaderIfMatch`（精确值 `If-Match`）。旧路径对该稳定名称执行 `strings.ToLower`，结果固定为 `if-match`，不需要重新生成字符串。
3. 非标准大小写、带参数或自定义 header 仍可能由内部测试/未来调用点传入，必须继续使用原有 `strings.ToLower` 语义，不能用宽泛的大小写折叠替代。
4. V98-01 只改变 header 名称规范化的分支选择；请求字段顺序、长度 framing、SHA-256、header 值读取、Storage/Locker、冲突和回放合同均保持不变。
5. V97-02/V97-03 仍为不可替代外部事项，不能由本地 fixture、loopback、miniredis 或文档声明关闭。

## 4. V98-01 实施约束与非目标

1. 不新增公开 API、配置、schema、operation、API version 或 release tag；只改变内部 header 名称规范化的分支选择。
2. 仅当输入精确等于 `fiber.HeaderIfMatch` 时返回常量 `if-match`；其它输入继续调用 `strings.ToLower`，保留原有 ASCII/Unicode 和非标准大小写行为。
3. 保留 method、URL、principal、媒体类型、header 名称和值、body 的顺序与长度前缀，保留 SHA-256 算法及 `[sha256.Size]byte` 返回类型。
4. 不改变 Storage/Locker I/O、常量时间冲突比较、响应缓存、replay header、ETag、认证授权顺序、超时、并发或错误 sentinel；不把本地 benchmark 外推为生产 RPS、p95/p99、RSS、GC、HA 或容量证据。
5. 不修改、构建、测试或计分 `MSFront`。

## 6. 架构、性能、内存与并发评估

幂等中间件仍先取得 namespaced lock，再计算指纹并绑定 Storage，响应缓存与解锁顺序不变。V98-01 的 helper 可被编译器内联，仅在精确 `If-Match` 分支返回静态字符串；mixed-case 和自定义 header 保留通用路径。Windows/amd64、Intel i5-10400、Go 1.27.1 下五轮完整指纹对照的分配均为优化 `216 B/op、8 allocs/op`、legacy `384 B/op、15 allocs/op`；ns/op 随调度在约 `1026–1070` 与 `1525–1635` 间波动，不作延迟或吞吐结论。Fiber `Ctx`、`hash.Hash` 接口和请求 body 转换造成的其余分配未在本轮扩大改动范围。真实 Redis 网络、并发容量、长稳和跨实例恢复仍属外部证据。

## 7. 安全、可靠性、数据与消息评估

header canonical fast path 返回 legacy `strings.ToLower("If-Match")` 的同一字节，不引入新的输入、密钥、哈希算法或可预测状态。指纹仍使用长度 framing 和 SHA-256；Storage 绑定继续执行常量时间冲突比较；If-Match/ETag、响应 replay、审计字段、Prometheus labels、SQL/Redis/outbox 和 JetStream settlement 语义不变。真实 HA、PITR、RPO/RTO、KMS/SIEM、正式身份与 exactly-once 继续 `not_recorded`。

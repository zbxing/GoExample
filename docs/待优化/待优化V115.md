## 3. V115-01 实施约束

- span 名称保持 `redis.connect`、`redis.auth/client/del/eval/evalsha/get/hello/ping/scan/select/set`、`redis._other` 与 `redis.pipeline`。
- `db.operation.name` 保持对应的 `CONNECT`、固定大写命令、`_OTHER` 与 `PIPELINE`。
- go-redis 常见小写命令走精确匹配；其他大小写通过无分配 case-insensitive 分支兼容；未知命令仍折叠为 `_other`。
- 不记录 command 参数、key、地址、凭据或 raw backend error；不改变 Lua、session、锁、Sentinel、timeout、cancel 或 error priority。

实测环境：Windows/amd64、Intel i5-10400、Go 1.27.1、默认 `GOMAXPROCS=12`、`-benchmem -count=5`。常见 `get` 从 `45.43-47.88 ns/op、8 B/op、1 alloc/op` 降至 `3.945-4.632 ns/op、0 B/op、0 allocs/op`；大写 `GET` 与未知命令也均降为 `0 B/op、0 allocs/op`。该结果只覆盖 operation helper，不外推 Redis 网络、吞吐、尾延迟、Sentinel failover 或生产容量。

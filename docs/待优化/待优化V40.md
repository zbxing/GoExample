## 3. V40-01 实施设计

### 3.1 Runner 接入

- `nginx-edge-contract.mjs` 只从 `scripts/lib/contract-command.mjs` 获取可注入 runner，不再导入或调用 `node:child_process`。
- 每次命令在 spawn 前校验参数和 deadline；默认 60 秒，镜像拉取 120 秒，日志、Git 和强制清理 30 秒。
- stdout 与 stderr 共享 8 MiB 上限；超限立即请求 `SIGTERM` 并分类为 `output overflow`。
- timeout、overflow、signal、spawn failure、missing status 和非零退出只结算一次；错误诊断最多 4,096 字符，不包含 args、密码或完整输出。
- `allowFailure` 仅用于 Git 身份探针、日志归档和 cleanup，普通命令失败立即中止合同并进入 finally 清理。

### 3.2 证据与测试

- 新增 Nginx 静态守卫：锁定 helper、超时常量、安全 spawn 选项，并拒绝直接 `spawn()`。
- 扩展合同 runner 行为矩阵，验证 stdout/stderr 合计上限，保留 timeout、signal、spawn、status 和诊断截断覆盖。
- 保留 Nginx evidence schema、场景顺序、固定镜像 digest、`targetEdge=not_recorded` 和 cleanup 语义。
- 更新 evidence input contract、manifest、SHA-256 和 graphify；不把本地合同结果写成目标 edge 证据。

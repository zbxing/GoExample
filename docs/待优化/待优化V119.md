## 3. V119-01 实施约束

- `canonicalTraceHeader` 对规范小写 `traceparent`/`tracestate` 先直接相等，只有不相等时才调用 `strings.EqualFold`；不改变长度分支和返回 canonical key。
- 必须覆盖两个 key 的全部 ASCII 大小写变体、非匹配长度、非 ASCII/控制字节输入，并与 legacy 结果逐项比较。
- `removeTraceHeaders` 的大小写不敏感删除、`traceCarrier` 的 W3C-only 读取、baggage 隔离、消息 body/header clone、Publish/Process 生命周期、错误和公开 API 全部不变。
- benchmark 输入在循环外构造并保留 test-only legacy carrier；规范小写路径必须可重复改善，mixed-case 不得明显回退，所有路径保持 `0 B/op、0 allocs/op`。

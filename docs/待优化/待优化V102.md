## 2. 全面复评结论

1. 架构所有权、协议边界、context fail-closed、body/header defensive clone、trace privacy、ack/DLQ/lease、幂等与 SQL 事务边界均有源码和测试证据。
2. 本地 benchmark 只支持相对分配/耗时比较：JetStream 单控制 header 约 73–76 ns/op、8 B/op、1 alloc/op；单普通 header 约 208–239 ns/op、344 B/op、3 allocs/op；64 headers 约 6.3–6.6 µs、4,960 B/op、5 allocs/op。不得外推生产 RPS、p95/p99、RSS、GC、HA 或容量。
3. 真实 edge/DNS/证书/HTTP/2/3、正式 IdP/MFA、生产 Redis/PostgreSQL/NATS、KMS/SIEM、跨主机恢复、RPO/RTO、远端 provenance 和组织审批不具备本地可替代证据。
4. 不把 loopback、fixture、miniredis、模拟 broker 或文档声明当作生产关闭条件；外部项保持 `not_recorded`。

## 3. V122-01 实施约束

1. 只替换 adapter 配置边界的 subject 合法性扫描，不改变公开 API、配置字段、subject 合法集合或任何 broker 请求。
2. 保留当前 `len` 上限、`.` 分隔规则、空 token 拒绝、`*`/`>` 拒绝、Unicode 空白/控制字符拒绝和所有调用方错误 sentinel。
3. 不把 UTF-8 字节扫描误当作 rune 语义；Unicode 空白与控制字符必须继续由 `unicode.IsSpace`/`unicode.IsControl` 判定。
4. 增加合法、空 token、通配符、超长、空白、控制字符和 Unicode 边界回归；加入 V121 对照 benchmark，输入在计时循环外构造。
5. 不改变 JetStream body/header 所有权、context、FetchMaxWait、ack/DLQ/lease、trace/baggage、重试或 public API。

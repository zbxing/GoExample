### 2.2 进程与环境引导缺口

`scripts/environment.mjs` 的根目录环境准备会执行根 Yarn 安装、仓库 Go 依赖 `mod download/verify` 以及 Go 归档解压。这些命令通过异步 `spawn` 继承输出，但当前没有入口级 timeout、终止信号或隐藏窗口选项；网络或工具链异常时可能无限等待，CI/本地初始化无法形成确定的失败边界。

`yarnTreeIsCurrent(frontRoot)` 只用于检查 MSFront 依赖树，明确保持原行为并排除在 V45-01 之外。V45-01 只为根目录 Yarn、仓库 Go 依赖和 Go 归档解压调用传入显式预算，不改变命令、参数、环境、输出或 MSFront 分支。

### 2.3 性能、资源与生命周期

- Framework 热路径已有 handler、trace、限流、幂等、ETag、queue header 和 transport 分配基准；固定 Linux、真实 payload、生产依赖和长稳容量仍需外部证据。
- evidence helper 已统一 timeout、非 shell、隐藏窗口、输出上限和 `SIGTERM`；V45 不改变 report/schema/artifact 或 verifier。
- 环境引导是剩余的仓库内进程生命周期缺口。增加有限预算只收敛异常路径，不宣称远端性能、生产容量或外部依赖可用性。

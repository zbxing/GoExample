## 3. V20-01 实施设计

### 3.1 环境隔离

- 在 `goEnvironment()` 复制 `process.env` 后，按键名大小写不敏感地删除 `GOROOT`。
- 不设置仓库路径或机器路径作为替代；Go 二进制必须使用自身编译时/相对安装根解析。
- 保持 `GO_BINARY` 的命令选择语义、`GOTOOLCHAIN=local`、`CGO_ENABLED=0`、Linux/amd64 目标、`GOCACHE`、`GOTMPDIR` 和 PATH 前置不变。
- `runReleaseTask()` 可以继续继承父进程环境，因为每个 build/verify 子任务都会在自身 `goEnvironment()` 中执行同一清理。

### 3.2 回归测试

- 扩展 release 测试运行器，允许对单次任务注入环境覆盖。
- 使用仓库内不存在的目录作为污染 `GOROOT`，避免依赖开发机安装另一个 Go 版本。
- 在污染环境下执行 canonical build、verify、reproducible 和第二次 reproducible；嵌套的两个隔离 witness 构建与校验也必须成功。
- 保留现有制品、manifest、源码闭包、checksum、ELF、路径穿越和篡改拒绝断言。

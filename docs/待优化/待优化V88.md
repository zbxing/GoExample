## 2. 复评发现

1. `scripts/go-sdk.mjs` 生成的包私有 `defaultSDKHTTPClient` 只配置 V87 的 `CheckRedirect`，`Timeout` 仍为零。
2. Go 的 `http.Client.Timeout == 0` 表示没有 client 级总时限。调用方传入无 deadline 的 `context.Background()` 时，response header、慢 body 与完整请求生命周期没有 SDK 兜底截止时间。
3. 默认 transport 的 dial/TLS 局部预算不能替代完整请求总预算；SDK 的 1 MiB 默认响应上限只限制字节数，不能限制等待时间。
4. V86 的 context 权威性依赖调用方 context；无 deadline context 不会自动变成有界请求。V87 只停止 redirect，不限制首个目标的等待时间。
5. 标准 `http.Client.Timeout` 覆盖连接、响应头和响应正文读取；30 秒能覆盖当前最长 5 秒示例延迟，又为通用 operation 留出保守余量。
6. `WithHTTPClient` 是显式注入边界，长任务或自定义 transport/proxy/jar 的调用方可完全接管 timeout；V88 不新增公开 option。
7. 该缺口可由双 SDK 同包测试确定性证明：`NewClient` 实际选中的 `*http.Client.Timeout` 修复前为零，修复后精确为 30 秒，同时原 redirect callback 保持 `http.ErrUseLastResponse`。

## 4. V88-01 实施约束与非目标

1. 规范源为 `scripts/go-sdk.mjs`；Example/Billing 的 `client.gen.go` 必须由生成命令产生，不手工漂移。
2. 使用包私有 `defaultSDKHTTPTimeout = 30 * time.Second`；不新增公开 API、option、环境变量、schema、operation、API version 或 release tag。
3. `defaultSDKHTTPClient` 同时设置 `Timeout` 与 V87 的 `CheckRedirect`，并保持包级共享和并发复用。
4. caller 更短 context deadline/cancellation 继续优先；V88 不延长 caller deadline，不新增 retry。
5. `WithHTTPClient` 完全覆盖默认 client；调用方实现的 timeout/redirect/transport/proxy/jar 行为不被包装。
6. 保持 V86 completed/late/nil/error/body ownership 和 V87 302/Location/Set-Cookie/body/target-zero contracts。
7. 默认路径只增加标准库 O(1) deadline/timer，不新增应用 goroutine、锁、body copy、header clone或网络往返。
8. 不把本地配置与行为测试宣称为真实 DNS/TLS/proxy/HTTP/2/3、生产 IdP、CPU/RSS、容量或长稳证据，不修改、构建、测试或计分 `MSFront`。

## 6. 性能与资源边界

V88 默认路径在调用方未提供更短 deadline 时增加一个由标准库管理的 O(1) 请求 timer/deadline，不增加 retry、额外网络请求、body copy、header clone、应用 goroutine、锁或后台状态。超时减少无限等待和资源长期占用风险，但本地测试不证明生产吞吐、延迟、CPU、RSS、连接池或容量改善。

## 7. 停止规则与允许终止接受条件

- 若实现需要改变公开 API/version/operation、延长 caller deadline、移除 `WithHTTPClient` 控制权或新增 retry/网络请求，则不得沿用 V88-01。
- 若任一 SDK timeout、redirect、V86回归、生成漂移、workspace、兼容、证据或非外部门禁失败，V88-01 不得标记完成，评分保持 `9.92018`。
- PostgreSQL recovery 因本机缺少 Linux Docker host 的失败必须保持有界、可验证和 `not_recorded`；不得伪造通过。
- V88-02/V88-03 只有取得对应不可变目标制品和独立验证，或由具名授权方批准并记录残余风险后，才可离开 `not_recorded`。

## 3. V117-01 实施约束

- 0-8 header 保留 V116 固定数组路径；9-64 才进入固定容量开放寻址 helper。
- header 名称先通过可见 ASCII 校验，再按 ASCII 大小写折叠哈希选择槽位；槽内原始名称必须用 `strings.EqualFold` 最终判等。
- 不同名称发生哈希或初始槽位碰撞时继续线性探测，不能误报重复，也不能覆盖已占用槽。
- `MaxHeaders > 64` 的公开配置继续使用既有 normalized-map 回退；不得把默认 64 误写成公开硬上限。
- 名称/值校验、数量/字节预算、body/header clone、W3C trace、context、panic、错误隐私和公开 API 均不变。

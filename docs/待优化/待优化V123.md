## 3. V123-01 实施合同

1. 保留循环外的空字符串和 255-byte 上限检查；删除独立 `strings.ContainsAny(subject, "*>")` 扫描。
2. 在现有 rune loop 内遇到 `*` 或 `>` 立即返回 false；`.` 继续以 `tokenHasCharacter` 拒绝前导、连续和尾随空 token。
3. 其他 rune 继续由 `unicode.IsSpace` 和 `unicode.IsControl` 判定；不得替换为仅 ASCII/byte 的不等价逻辑。
4. 增加 `*`/`>` 位于开头、中间、结尾和 token 内的行为矩阵；锁定所有 adapter 构造调用方原有配置 sentinel。
5. 扩展永久 benchmark，至少覆盖合法、Unicode、空 token、空白以及不同位置通配符；输入必须在计时循环外构造。
6. 不改变 JetStream body/header 所有权、FetchMaxWait、context、ack/DLQ/lease、trace/baggage、重试、public API 或配置 schema。

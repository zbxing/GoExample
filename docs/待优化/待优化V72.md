## 2. 复评发现

refresh-token `RotateSession` 原先先执行 token hash 的 `GET`，再执行 Lua family 旋转；`RevokeFamily` 也先 GET 再执行 Lua。该路径是高频共享状态热路径，存在额外 Redis 往返和两命令状态窗口。缺口位于 `Framework/sharedstate`，不需要真实硬件、目标 Redis 或外部审批即可闭环。

## 4. V72-01 实施约束

1. 不新增 goroutine、锁、后台状态、公开 API、HTTP/OpenAPI/SDK operation 或配置键。
2. Lua 在单次调用内读取 token 映射、校验 32 字符小写 hex family ID、派生 family/used key、检查 absolute/current/revoked/expires/history，并完成轮换或撤销。
3. 返回值有界且只使用既有 `ErrSessionInvalid`、`ErrSessionExpired`、`ErrSessionRevoked`、`ErrSessionReuse`、`ErrSessionLimit` 语义；malformed 映射 fail closed。
4. 原始 token、CSRF、user ID 明文、family 内部 key、payload、provider/body 和 Redis backend 错误不得进入错误、日志或 span；旧 token 映射保留至 TTL 以继续检测 replay。
5. 本地 miniredis 与 telemetry 命令数测试只证明 adapter 行为，不证明生产 Redis 延迟、吞吐、HA、容量、eviction、跨主机恢复或 exactly-once。

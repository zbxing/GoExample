## 2. 工作包

### V127-01：修复 gRPC 已知漏洞（P0，已完成）

首次执行 `yarn vuln:server` 时，`google.golang.org/grpc v1.83.0` 命中 `GO-2026-6348`；官方修复版本为 `v1.83.1`。已统一升级以下模块并刷新 `go.sum`：

- `Framework`
- `Solutions/Example`
- `support/consumer/HealthProbe`

约束：

- 只更新受影响依赖和校验和，不修改业务实现、公开 API、生成代码、配置、schema 或错误边界。
- 三个模块必须保持同一 gRPC 补丁版本，不保留 `v1.83.0` 校验和。
- `govulncheck` 必须报告项目代码受影响漏洞为 0；仅存在于未调用模块路径的提示不冒充可达漏洞。
- test、race、vet、build、API、release、Node、evidence、Graphify 或 MSFront 范围门禁任一失败，取消增分并恢复 `9.931032`。

验收结果：

1. 三个 go.mod 均为 `google.golang.org/grpc v1.83.1`，go.sum 与官方 checksum 一致。
2. `yarn vuln:server` 通过，项目代码受影响漏洞为 0。
3. `yarn test:server`、`yarn race:server`、`yarn vet:server`、`yarn build:server`、`yarn api:compat`、release build/verify、evidence manifest/verifier 均通过。
4. `yarn test:node` 主组 `215/215`、release 组 `5/5` 通过。
